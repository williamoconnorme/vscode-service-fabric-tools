# Open a Service Fabric application

The extension activates automatically when a workspace contains any `*.sfproj` file. After activation:

- The **Service Fabric** view appears in the activity bar.
- The **Applications** tree lists every `.sfproj` plus its application/service manifests, default services, parameters, publish profiles, and scripts.
- Manifest XML files get inline diagnostics (parameter usage, version drift, duplicates).

If you don't have a Service Fabric project yet, use **Service Fabric: Create New Application…** to scaffold one.
