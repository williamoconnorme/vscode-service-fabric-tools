# How-to guide

The bundled help guide is a single, comprehensive how-to that documents every feature of the extension and is shipped inside the VSIX so it works offline.

It covers:

- Project recognition & the activity-bar tree
- Manifest authoring, schema validation, F12, code actions, `SFD00x` diagnostics
- Build, rebuild, clean, package via MSBuild
- Local development cluster (1-node and 5-node)
- Connecting to local + remote clusters
- Deploy / Remove
- Attaching the debugger to a deployed service
- Diagnostic events webview
- Scaffolding new applications
- Every setting and command, with troubleshooting and FAQ

Run **Service Fabric: Open Help Guide** any time, or click the book icon in the **Service Fabric** view title bar.
